HARU Calendar

개인정보처리 안내

이 안내는 직원용 Windows HARU Calendar의 Google 일정 연결 및 로컬 저장에 적용됩니다. 별도로 구성한 NAS 공유 서비스는 해당 관리자의 보관·접근 설정도 확인해야 합니다.

처리하는 정보와 목적

  • Google 이메일 주소와 계정 식별자: 로그인한 계정을 확인하고 다른 계정과 일정이 섞이는 것을 방지합니다.
  • Google 인증 토큰: 사용자가 승인한 전용 캘린더에 접근하고 자동 동기화를 유지합니다.
  • 일정 본문, 날짜, 변경·삭제 상태 및 동기화 식별 정보: HARU 일정과 Google의 HARU 전용 캘린더를 동기화합니다.
  • 로컬 메모, 화면·연결 설정: PC 내 메모 관리와 프로그램 동작에 사용합니다. Google 연결 기능은 로컬 메모를 Google에 전송하지 않습니다.

저장과 전송

Windows 직원 배포판은 일정·메모·연결 설정과 인증 토큰을 현재 Windows 사용자 계정에 연결된 암호화 저장소에 보관합니다. Google 연결 시 필요한 일정과 인증 요청을 Google API로 전송합니다. 프로그램은 Google 계정 비밀번호를 저장하지 않습니다. Google 일정 데이터와 토큰을 공개 안내 사이트, 광고 서비스 또는 AI 학습 용도로 전송하지 않습니다.

사용자가 별도로 설정한 현장 감시 서버, NAS 공유 및 프로그램 업데이트 서버에는 각 기능에 필요한 요청이 발생합니다. 회사의 데이터 공유·백업 설정은 담당자에게 확인하세요.

보관, 연결 해제와 삭제

로컬 데이터는 사용자가 삭제할 때까지 PC에 남을 수 있으며 프로그램 제거만으로 데이터가 삭제되지 않을 수 있습니다. Google 계정의 타사 연결 관리에서 HARU 접근 권한을 취소할 수 있습니다. 권한 취소는 Google 캘린더나 PC의 기존 일정을 자동 삭제하지 않습니다. 삭제하려면 Google Calendar의 HARU 전용 캘린더와 PC 데이터·백업을 각각 확인해야 합니다. 담당자는 요청 시 삭제 절차를 안내합니다.

정보 이용 제한

HARU Calendar의 Google API 정보 이용과 다른 앱으로의 전송은 제한적 이용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. Google 사용자 데이터를 판매하거나 맞춤 광고 및 범용 AI 모델 학습에 이용하지 않습니다.
