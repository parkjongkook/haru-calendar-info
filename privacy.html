HARU Calendar

개인정보처리 안내

이 안내는 직원용 Windows HARU Calendar와 휴대폰용 하루 메모의 Google 연결 및 저장에 적용됩니다. 별도로 구성한 NAS 공유 서비스는 해당 관리자의 보관·접근 설정도 확인해야 합니다.

처리하는 정보와 목적

  • Google 이메일 주소와 계정 식별자: 로그인한 계정을 확인하고 다른 계정과 일정이 섞이는 것을 방지합니다.
  • Google 인증 토큰: 사용자가 승인한 전용 캘린더와 하루 메모 저장 공간에 접근합니다. Windows는 자동 갱신 토큰을 암호화 저장하며, 휴대폰 웹 화면의 접근 토큰은 페이지 메모리에만 보관합니다.
  • 일정 본문, 날짜, 변경·삭제 상태 및 동기화 식별 정보: HARU 일정과 Google의 HARU 전용 캘린더를 동기화합니다.
  • 메모 본문·제목·색상·변경 및 삭제 기록: 하루 메모 연결을 승인한 경우 Google Drive의 앱 전용 비공개 공간으로 전송하여 기기 간 동기화합니다. 일반 Drive 파일 전체에 접근하는 권한은 요청하지 않습니다. 화면·연결 설정은 프로그램 동작에 사용합니다.

저장과 전송

Windows 직원 배포판은 일정·메모·연결 설정과 인증 토큰을 현재 Windows 사용자 계정에 연결된 암호화 저장소에 보관합니다. Google 연결 시 필요한 일정·메모와 인증 요청을 Google API로 전송합니다. 휴대폰 웹 화면은 메모 사본과 전송 대기 내용을 해당 브라우저의 로컬 저장 공간에, 작성 중인 내용은 세션 저장 공간에 보관합니다. 브라우저 저장 공간은 Windows 암호화 저장소와 다르므로 개인 기기에서 사용하세요. 프로그램은 Google 계정 비밀번호를 저장하지 않습니다. Google 일정 데이터와 토큰을 공개 안내 사이트, 광고 서비스 또는 AI 학습 용도로 전송하지 않습니다.

사용자가 별도로 설정한 현장 감시 서버, NAS 공유 및 프로그램 업데이트 서버에는 각 기능에 필요한 요청이 발생합니다. 회사의 데이터 공유·백업 설정은 담당자에게 확인하세요.

보관, 연결 해제와 삭제

로컬 데이터는 사용자가 삭제할 때까지 PC에 남을 수 있으며 프로그램 제거만으로 데이터가 삭제되지 않을 수 있습니다. Google 계정의 타사 연결 관리에서 HARU 접근 권한을 취소할 수 있습니다. 권한 취소는 Google 캘린더나 PC의 기존 일정을 자동 삭제하지 않습니다. 메모 삭제는 기기 간 반영되는 숨김 처리이며 복원과 동시 수정 보호를 위해 이전 변경 기록이 남습니다. 전체 삭제는 Google Drive의 앱 관리에서 HARU의 숨겨진 앱 데이터를 삭제하고 PC·브라우저 사본 및 백업도 별도로 삭제해야 합니다. Google Calendar의 HARU 전용 캘린더는 별도로 관리합니다. 휴대폰 화면의 로그아웃은 전송 완료 후 해당 브라우저의 메모 사본을 지우며 Google 원본은 유지합니다. 담당자는 요청 시 삭제 절차를 안내합니다.

정보 이용 제한

HARU Calendar의 Google API 정보 이용과 다른 앱으로의 전송은 제한적 이용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. Google 사용자 데이터를 판매하거나 맞춤 광고 및 범용 AI 모델 학습에 이용하지 않습니다.

안내 웹사이트

앱 안내·개인정보·이용 안내 페이지에는 광고·분석 스크립트가 없습니다. 휴대폰 메모 화면은 Google 공식 로그인 스크립트를 사용하며 메모는 브라우저와 Google 사이에서 직접 전송됩니다. GitHub에 공개하는 파일에는 개인 메모·일정·접근 토큰·PC 프로그램 소스가 포함되지 않습니다. GitHub Pages에 게시되는 경우 호스팅 제공자는 보안 목적으로 방문자의 IP 주소 등 접속 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 참고하세요.
